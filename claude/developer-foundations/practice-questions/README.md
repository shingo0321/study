### Q1 ([ドメイン02: Applications and Integration](../topics/02-applications-and-integration/notes.html))

Claude Messages APIを使ったマルチターンのチャットアプリケーションを実装している。2ターン目のリクエストで、Claudeが1ターン目の内容を踏まえた応答をするために、開発者側が行うべきことはどれか。

A. 1ターン目の応答だけを`system`パラメータに入れて、2ターン目のユーザー発言と一緒に送信する。<br>
B. 何もしなくてよい。ClaudeのAPIはサーバー側でセッション状態を保持しているため、直前までの会話内容を自動的に参照して応答する。<br>
C. `session_id`パラメータを付与すれば、サーバー側が過去の会話履歴を自動的に参照して応答する。<br>
D. 1ターン目のユーザー発言とAssistantの応答を含む会話履歴全体を、`messages` 配列に含めて毎回送信する。

**正解: D**

解説: Messages APIはステートレスであり、会話の継続にはクライアント側で全履歴を組み立てて毎回送信する必要がある。

### Q2 ([ドメイン02: Applications and Integration](../topics/02-applications-and-integration/notes.html))

以下のうち、プロンプトキャッシュの効果が最も期待できるユースケースはどれか。

A. 毎回まったく異なるユーザーから届く、内容がほとんど重複しない単発の質問に、個別に答えるチャットボット。<br>

C. 出力トークン数を最小化することだけが目的で、入力はリクエストごとに大きく変わるタスク。<br>

### Q3 ([ドメイン02: Applications and Integration](../topics/02-applications-and-integration/notes.html))

ツールユース(function calling)のフローとして正しい順序はどれか。

A. 開発者がツールを定義してリクエストに含める → Claudeが`tool_use`で呼び出したいツールと引数を返す → クライアント側がツールを実行する → 実行結果を`tool_result`として会話に追加し再度リクエストする<br>
B. 開発者がツールを定義してリクエストに含める → Claudeがツールを直接実行して結果を得る → Claudeが実行結果を踏まえた最終応答を返す<br>
C. クライアントが先にツールを実行する → その結果だけをClaudeに渡す → Claudeが`tool_use`でツール名と引数を返す → クライアント側が結果を確認して最終応答を作る<br>

解説: ツールの実際の実行はAPI側ではなくクライアント側の責務であり、Claudeは「何を呼びたいか」を`tool_use`として返すだけである。
