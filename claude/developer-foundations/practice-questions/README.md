### Q1 ([ドメイン02: Applications and Integration](../topics/02-applications-and-integration/notes.html))

Claude Messages APIを使ったマルチターンのチャットアプリケーションを実装している。2ターン目のリクエストで、Claudeが1ターン目の内容を踏まえた応答をするために、開発者側が行うべきことはどれか。

A. 1ターン目の応答だけを`system`パラメータに入れて送信する。<br>
B. 何もしなくてよい。ClaudeのAPIはサーバー側でセッション状態を保持している。<br>
C. `session_id` パラメータを付与すれば、サーバー側が履歴を自動的に参照する。<br>

**正解: D**

解説: Messages APIはステートレスであり、会話の継続にはクライアント側で全履歴を組み立てて毎回送信する必要がある。

### Q2 ([ドメイン02: Applications and Integration](../topics/02-applications-and-integration/notes.html))

以下のうち、プロンプトキャッシュの効果が最も期待できるユースケースはどれか。

A. 毎回まったく異なるユーザーからの、内容が重複しない単発の質問に答えるチャットボット。<br>
B. 同一の長いシステムプロンプトと同一のツール定義セットを使い、多数のリクエストを継続的に送るカスタマーサポートエージェント。<br>
C. 出力トークン数を最小化したいだけのタスク。<br>

解説: 問題が統合レイヤーにあるのかモデルの出力にあるのかを、トレースで各ステップの入出力を確認して切り分ける。

### Q52 ([ドメイン02: Applications and Integration](../topics/02-applications-and-integration/notes.html))

あなたは、Claude APIを使うアプリの開発者です。リクエストのたびに同じ長いシステムプロンプトを送っており、コストを下げたいです。プロンプトキャッシュの効果を得るために適切なものを2つ選択してください。

A. ユーザーごとに変わる内容は、キャッシュ対象の後ろに置く<br>
B. 毎回、先頭にタイムスタンプを入れて、リクエストを区別する<br>
C. 変わらない部分(システムプロンプト、ツール定義)をプロンプトの先頭にまとめる<br>
D. システムプロンプトの順序を、リクエストごとに入れ替える

**正解: A, C**

解説: キャッシュは、先頭から同一の部分に効く。変わらない部分を先頭に固定し、変わる部分を後ろに置く。先頭に毎回変わる値を入れたり、順序を入れ替えたりすると、キャッシュが効かなくなる。
